# 境町 ↔ 東京 高速バス ミニ（非公式）

https://sakaimachi-bus.amida-des.com/

境町（境町高速バスターミナル）と東京（王子駅・東京駅）を結ぶ高速バスの時刻を、
**開いた瞬間に**確認できるファンメイドの Web アプリです。検索も入力も不要で、
次に乗れる便とそこまでの残り時間がそのまま表示されます。

---

## できること

### 「今から乗れる便」が 0 タップで分かる
- 次に出発する便を大きく表示し、残り時間をカウントダウン
- 「バス停まで徒歩◯分」を設定しておくと、**間に合います／そろそろ出発／急いでください**を色で判定
- 発 → 経由 → 着のタイムラインと所要時間、乗車するのりばを 1 枚のカードに集約
- 最終便を過ぎたら、自動で翌営業日の始発に切り替わる

### 1 日の全便を俯瞰できる
- その日の全便を一覧表示。次発をハイライトし、発車済みは減光
- 今日 / 明日 / 明後日 / 任意の日付に切り替え可能
- 土曜・日曜に加えて**祝日・振替休日・国民の休日も自動で土日祝ダイヤ**に切り替わる
- 東京発は乗車停留所（東京駅 / 王子駅）を選ぶと、その停留所の発車時刻が基準になる

### 移動の準備までつながる
- 便を選ぶと**カレンダー（.ics）に追加**できる。徒歩時間＋5分前にアラームつき
- 便の情報を共有・コピー
- のりばを地図で開く
- ホーム画面に追加すればアプリのように起動し、**オフラインでも時刻表を確認できる**
- OS 設定に追従するダークモード（手動切替も可能）

## 情報の正確さについて

- 公開されている時刻表をもとにした**固定ダイヤ**です。当日の遅延・運休は反映されません。
- データには改定日・出典・最終確認日を持たせています。
  **未反映の改定が告知されている場合は、全ページ上部でお知らせし一次情報へ誘導します。**
- 運賃は改定されることがあるため、金額は掲載せず公式ページへ案内しています。
- 本アプリは境町・運行事業者の公式サービスではありません。最新情報は必ず
  [関東鉄道](https://www.kantetsu.co.jp/highwaybus/sakai-tokyo) ／
  [JRバス関東](https://www.jrbuskanto.co.jp/) ／
  [境町公式サイト](https://www.town.ibaraki-sakai.lg.jp/page/page002622.html) をご確認ください。

## 開発者向け

Astro + React + TypeScript。ランタイム依存は React のみで、日時処理は `Intl` ベースの自前実装です。

```bash
npm install
npm run dev                  # 開発サーバー
npm run verify               # データ検証 → ユニットテスト → 型チェック → ビルド
npm run validate:timetable   # 時刻表データの機械検証
npm test                     # ロジックのユニットテスト
npm run test:e2e             # ブラウザ実機の回帰テスト（要: dist の配信）
```

主なモジュール:

| パス | 役割 |
|------|------|
| `src/lib/jst.ts` | Asia/Tokyo の壁時計。時刻はすべて「0:00 からの経過分」で扱う |
| `src/lib/holidays.ts` | 日本の祝日判定（振替休日・国民の休日・春分/秋分・五輪特例） |
| `src/lib/timetable.ts` | 時刻表スキーマと正規化（旧フォーマット互換） |
| `src/lib/schedule.ts` | 次発・全便・日跨ぎ・間に合うかの判定 |
| `src/data/timetable.json` | 時刻表データ（改定日・出典・最終確認日を含む） |

時刻表の更新手順と改善の経緯は [IMPROVEMENT_PLAN.md](IMPROVEMENT_PLAN.md)、
開発フローは [CONTRIBUTING.md](CONTRIBUTING.md) を参照してください。
